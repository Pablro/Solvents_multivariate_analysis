# Análisis multivariable de solventes

Este es el código original. Actualmente está pasando por actualizaciones y correcciones. 

## Acerca del dataset:
Metadata:

Link de referencia del dataset: https://openmv.net/info/solvents

Autor del dataset: Kevin Dunn

Última actualización del dataset: 11/11/2018

Descripción del dataset: El data se compone de 103 filas (solventes + header) y 10 columnas (propiedades físico-químicas+nombre del solvente). Estas propiedades son: punto de fusión, punto de ebullición, constante dieléctrica del solvente, momento dipolar, indice de refractividad, ET30, densidad, logP y solubilidad.

Formato del dataset: Es un archivo en formato csv (comma separated values)

Repositorio del dataset: OpenMV

Acerca del repositorio: Es un repositorio que pertenece al libro de que a su vez tiene un uso divulgativo y esta conectada a la pagina del autor
